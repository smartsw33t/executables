# பேசுபொருள் - தமிழ் கணினி மென்பொருள்கள் (Pesuporul Tamil Desktop Softwares)

தமிழ் மக்களுக்கு அன்றாடக் கணினிப் பயன்பாட்டில் நேரடியாகப் பயன்படக்கூடிய, முழுமையான தமிழ் செயலாற்றும் திரையுடன் உருவாக்கப்பட்ட இலவச Windows கணினி மென்பொருள்களின் அதிகாரப்பூர்வத் தொகுப்பு.

An official collection of free Windows desktop applications engineered with natural, conversational Tamil interfaces for everyday productivity, media creation, and accessible web browsing.

## 📦 மென்பொருள்கள் பட்டியல் / Included Softwares

1. **ஆறாவமுதம் வீடியோ பிளேயர் (Aaravamudham Video Player)**
   - **தமிழ்:** படத்திற்குள் படம், `.srt` வசனங்கள் ஆதரவு, வேகக் கட்டுப்பாடு மற்றும் எளிய தமிழ் வழிசெலுத்தலுடன் கூடிய அசையும்பட இயக்கி.
   - **English:** Desktop media player featuring Picture-in-Picture, `.srt` subtitle support, playback speed controls, loop, and shuffle modes.

2. **அதியமான் வீடியோ எடிட்டர் (Adhiyamaan Video Editor)**
   - **தமிழ்:** இணைய இணைப்பின்றி அசையும்படங்களை வெட்டவும், இணைக்கவும், தமிழ் வாசகங்கள் மற்றும் இசை சேர்த்து உயர்தர MP4 கோப்பாக மாற்றவும் உதவும் கருவி.
   - **English:** Offline desktop video editor to trim and merge clips, add customizable Tamil captions and audio tracks, and export in MP4.

3. **ஐம்புலம் ரீல்ஸ் மேக்கர் (Aimbulam Reels Maker)**
   - **தமிழ்:** கணினிப் படப்பிடிப்பு சாதனம் வழியாகக் குறும்படச்சுருள்கள் மற்றும் அசையாப்படங்களைப் பதிவு செய்து, தமிழ் வாசகங்கள், உணர்வீகள் மற்றும் சிறப்புக் காட்சியமைப்புகளைச் சேர்க்கும் மென்பொருள்.
   - **English:** Desktop camera and reels studio to record vertical short videos and photos with Tamil text overlays, emojis, and visual filters.

4. **ஈடு ஃபைல் கம்பிரசர் (Eedu File Compressor)**
   - **தமிழ்:** பெரிய கோப்புகள், அசையாப்படங்கள் மற்றும் பிடிஎஃப் ஆவணங்களின் அளவைத் தரம் குறையாமல் சுருக்கவும், தொகுப்புக் கோப்புகளை விரிவாக்கம் செய்யவும் உதவும் கருவி.
   - **English:** Offline file compression utility to shrink large files, images, and PDFs without losing quality, complete with built-in archive extraction.

5. **இசைஞானி மியூசிக் கம்போசர் (Isaignani Music Composer)**
   - **தமிழ்:** ச-ரி-க-ம-ப-த-நி ஏழு சுரங்களைக் கொண்டு பல இசைக்கருவிகளின் ஓசையில் புதிய மெட்டுகளை உருவாக்கவும், குரல் பதிவு செய்து MP3-ஆகச் சேமிக்கவும் உதவும் இசைத் தொகுப்பி.
   - **English:** Seven-swara music composition studio with multi-instrument playback, vocal recording, and high-quality MP3/WAV export.

6. **உகரம் பிரவுசர் (Ugaram Browser)**
   - **தமிழ்:** தமிழ் மொழிப் பயன்பாட்டிற்கும், அனைவரும் எளிதில் கையாளக்கூடிய வடிவமைப்பிற்கும் முன்னுரிமை அளித்து உருவாக்கப்பட்ட வேகமான மற்றும் பாதுகாப்பான இணைய உலாவி.
   - **English:** Fast, privacy-focused desktop web browser built with native Tamil navigation, multi-tab management, and inclusive accessibility.

## ⬇️ பதிவிறக்கம் செய்வது எப்படி? / How to Download

1. இந்தப் பக்கத்தின் வலதுபுறம் உள்ள **Releases** பகுதிக்குச் செல்லவும் (அல்லது [Releases](../../releases) இணைப்பைச் சொடுக்கவும்).
2. உங்களுக்குத் தேவையான மென்பொருளின் `.exe` நிறுவியைத் தேர்ந்தெடுத்துப் பதிவிறக்கம் செய்யவும்.
3. உங்கள் Windows 10 அல்லது Windows 11 (64-bit) கணினியில் கோப்பை இயக்கி நிறுவிக்கொள்ளவும்.

1. Navigate to the **Releases** section on the right sidebar (or click [Releases](../../releases)).
2. Select and download the `.exe` installer for your preferred application.
3. Run the installer on your Windows 10 or Windows 11 (64-bit) PC.
